\begin{frame}{The Problem: Author H5ADs Are Not Comparable Enough}
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.48\textwidth}
      \textbf{What we receive}
      \begin{tightitemize}
        \item Processed H5AD files made for individual papers.
        \item Different references, gene symbols, filtering, normalization, and guide annotations.
        \item Metadata fields that use study-specific names and assumptions.
      \end{tightitemize}
    \end{column}
    \begin{column}{0.48\textwidth}
      \textbf{Why it matters}
      \begin{tightitemize}
        \item Cross-study comparison inherits author-specific processing choices.
        \item Aggregating datasets can amplify processing batch effects.
        \item Catalogue users expect one clear schema, one count definition, and one perturbation label definition.
      \end{tightitemize}
    \end{column}
  \end{columns}
  \vspace{0.7em}
  \textbf{Decision:} reprocess from FASTQ with one reference, one expression workflow, one guide workflow, and one QC policy.
\end{frame}

\begin{frame}{Constraints and Data Issues}
  \footnotesize
  \renewcommand{\arraystretch}{1.22}
  \begin{tabularx}{\linewidth}{L{0.22\linewidth}Y}
    Data volume & The five completed datasets use about 19 TB of FASTQs; the largest single dataset is about 11 TB. \\
    Compute budget & Storage and cluster time are adequate but not unlimited, so the pipeline must be fast enough to rerun. \\
    Cell Ranger & Useful, but too slow for repeated catalogue-scale reprocessing of these datasets. \\
    FASTQ source & ENA FASTQs did not include the required technical barcode/UMI reads for these runs; the current workaround uses SRA downloads. \\
    ENA metadata & Sample names, lanes, SRRs, and library names are not consistent across studies and need dataset-specific grouping. \\
    10x details & Expression and guide libraries can use related but non-identical barcodes; the pipeline applies the required KITE barcode correction. \\
  \end{tabularx}
\end{frame}

\begin{frame}{Solution: Fully Automated FASTQ-to-H5AD Pipeline}
  \centering
  \includegraphics[width=0.94\linewidth,height=0.54\textheight,keepaspectratio]{pipeline_workflow.pdf}
  \vspace{0.1em}
  \footnotesize
  \begin{tightitemize}
    \item One Nextflow run builds references, groups FASTQs by physical well, quantifies expression and guides, aligns barcodes, and writes a single H5AD.
    \item Per-sample guide diagnostics are written before final merge, so failures are visible before downstream analysis.
  \end{tightitemize}
\end{frame}

\begin{frame}{Why kallisto+bustools?}
  \begin{tightitemize}
    \item \textbf{Fast enough to rerun:} catalogue processing needs iteration, not a one-off run.
    \item \textbf{Open and scriptable:} the same workflow can run in Nextflow with containerized dependencies.
    \item \textbf{Two modalities:} standard count mode handles expression; KITE mode handles guide barcodes.
    \item \textbf{Works within budget:} lower wall time and storage pressure make full reprocessing practical.
    \item \textbf{Comparable output:} QC shows high agreement with author baselines where direct comparison is meaningful.
  \end{tightitemize}
\end{frame}

\begin{frame}{Guide Calling}
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.56\textwidth}
      \begin{tightitemize}
        \item KITE produces a guide UMI matrix aligned to expression barcodes.
        \item A Gaussian-Poisson mixture separates low-count background from true guide signal.
        \item The decision threshold is the crossover where signal is more likely than background.
        \item Probe calls are collapsed to gene-level outcomes: control, single gene, multi-gene, mixed gene/control, or unassigned.
        \item Valid single-gene analysis uses exactly one gene-targeting call and no control guide call.
      \end{tightitemize}
    \end{column}
    \begin{column}{0.40\textwidth}
      \footnotesize
      \renewcommand{\arraystretch}{1.2}
      \begin{tabular}{lc}
        \toprule
        Dataset group & Threshold \\
        \midrule
        Nadig HepG2 & 8 UMI \\
        Nadig Jurkat & 8 UMI \\
        K562 Essential & 8 UMI \\
        K562 Genome-wide & 8 UMI \\
        RPE1 Essential & 9 UMI \\
        \bottomrule
      \end{tabular}
      \slidenote{Thresholds come from the fitted mixture model for each dataset.}
    \end{column}
  \end{columns}
\end{frame}

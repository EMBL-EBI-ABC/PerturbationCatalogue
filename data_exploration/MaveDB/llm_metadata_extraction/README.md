# Historical MaveDB metadata extraction

This directory retains legacy extraction outputs, logs, the old Instructor
cache, and an example notebook for reference. The example imports the retired
extraction implementation and is not part of the supported workflow.

For current work, start with the
[study curation workflow](../../curation_tools/study_curation/README.md).
The active source records and lookup maps have moved to
`data_exploration/curation_cache/mavedb/`; publication files live in
`data_exploration/curation_cache/publications/`.

Existing extraction outputs and historical run folders have been preserved.
